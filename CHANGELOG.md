# Release Notes for Copy Field

All notable changes to this project will be documented in this file.

## 2.1.0 - 2026.10.30
### Added
- Full compatibility with PHP `^8.2 || ^8.3 || ^8.4 || ^8.5` and Craft CMS `^5.0.0`
- PHPStan Level 8 static analysis configuration (`phpstan.neon`)
- Code quality scripts in `composer.json` (`check-cs`, `fix-cs`, `phpstan`, `pint`, `pint-test`, `rector`)

### Changed
- Modernized type hints, closure returns, and docblocks across plugin and field classes
- Formatted source code to PSR-12 code style with Laravel Pint
- Updated `composer.json` metadata (`developer`, `developerUrl`, `documentationUrl`)
